1) Коллайдер (Collider) — это физический компонент, который определяет границы объекта для физического движка, чтобы он мог осязать другие объекты и не проваливаться сквозь них.
Коллизия (Collision) — это сам факт физического столкновения между двумя объектами, а также класс (Collision), который передается в метод обработки столкновения и содержит всю информацию о месте удара, скорости и объекте, с которым произошло соприкосновение.
2) while (цикл с предусловием): Сначала проверяет условие. Если оно истинно, то выполняет код внутри цикла. Если условие изначально ложно, код внутри не выполнится ни разу.
do-while (цикл с постусловием): Сначала выполняет блок кода один раз, а только потом проверяет условие в конце. Это гарантирует, что код выполнится минимум один раз, даже если условие сразу ложно.
3) GET - используется для получения данных с сервера.
POST - используется для отправки новых данных на сервер.
PUT/PATCH  обновление существующих данных на сервере.
DELETE  удаление данных с сервера.
4) OnCollision (OnCollisionEnter и др.) — используется для физических (твердых) столкновений, когда объекты должны отталкиваться друг от друга (например, бильярдные шары, стены, прыжки по платформам). У объектов должны быть коллайдеры (без галочки Is Trigger) и обязательно компонент Rigidbody.
OnTrigger (OnTriggerEnter и др.) — используется, когда объекты должны пролетать сквозь друг друга, но при этом регистрировать факт пересечения (например, подбор монетки, вход в зону чекпоинта, триггер открытия двери). У одного из коллайдеров должна стоять галочка Is Trigger.
5) Input нужен для считывания действий игрока: нажатий клавиш клавиатуры, движений мыши, кликов или ввода с геймпада/сенсорного экрана.
