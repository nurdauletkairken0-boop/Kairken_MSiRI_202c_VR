1) Класс - это шаблон (чертеж), описывающий состояние и поведение будущих объектов. Задает какие поля и методы будут у объектов, сами по себе данных не хранят.
2) Переменная класса - это ссылка, хранит ссылку на объект, а сами данные не хранят.
3) null - отсутствие ссылки, обращение к членам null вызовет NullReferenceException.
4) Поле - хранит данные конкретного объекта, метод - описывает поведение объекта - действия над ее полями. 
Объединение позволяет связать данные с функциями, которые ими управляют.


1)  Защита целостности данных: Открытые поля позволяют внешне присваивать некорректные значения, из за чего объект может оказаться в недопустимом состоянии.
2) Поле — это непосредственное хранилище данных, в то время как свойство — это механизм доступа к полю.
3) Компилятор автоматически сгенерирует стандартный конструктор по умолчанию (без параметров), который инициализирует все поля их значениями по умолчанию
4) Конструктор дополняет инкапсуляцию, обеспечивая контролируемое создание объекта. Так как внутренние поля скрыты, внешний код не может присвоить им значения напрямую. Конструктор принимает параметры , проверяет их и безопасно инициализирует скрытое состояние, гарантируя что объект создается корректно. 
5) Нет, свойство только для чтения нельзя изменить после того, как объект был создан.
